# 박문지부 영무궁화 연찬회

## 최종 GitHub 구조

박문 저장소의 최상위에 아래 파일을 넣습니다.

- index.html
- manifest.json
- sw.js
- 404.html
- README.md
- .nojekyll
- 박문 사진/ (기존 폴더 그대로 유지)

`박문 사진` 폴더에는 다음 파일이 있어야 합니다.

`슬라이드1.PNG` ~ `슬라이드78.PNG`

**확장자는 반드시 대문자 PNG입니다.**
