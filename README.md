# 박문지부 영무궁화 연찬회

## GitHub 저장소 구조

```text
박문/
├── index.html
├── manifest.json
├── sw.js
├── 404.html
└── 박문 사진/
    ├── 슬라이스1.png
    ├── 슬라이스2.png
    ├── ...
    └── 슬라이스78.png
```

## 업로드 방법

1. 이 ZIP의 파일들을 GitHub 저장소 **최상위(root)** 에 업로드합니다.
2. 기존 `박문 사진` 폴더는 삭제하지 않습니다.
3. `박문 사진` 폴더 안에 `슬라이스1.png`부터 `슬라이스78.png`가 있어야 합니다.
4. GitHub의 **Settings → Pages**에서:
   - Source: **Deploy from a branch**
   - Branch: **main**
   - Folder: **/ (root)**
   - Save
5. 잠시 기다린 뒤 GitHub Pages 주소로 접속합니다.
