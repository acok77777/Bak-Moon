# 박문 사진 웹페이지

## GitHub에 올리는 방법

저장소에 아래처럼 넣어 주세요.

- `index.html`
- `style.css`
- `script.js`
- `박문 사진/`
  - `슬라이스1.png`
  - `슬라이스2.png`
  - ...
  - `슬라이스78.png`

이미 저장소에 `박문 사진` 폴더와 슬라이스 이미지가 있다면,
이 ZIP에서 `index.html`, `style.css`, `script.js`만 올려도 됩니다.

## 사진 연결

- 첫 화면: `슬라이스1.png`
- 1번: `슬라이스2.png` ~ `슬라이스11.png`
- 2번: `슬라이스12.png` ~ `슬라이스20.png`
- 3번: `슬라이스21.png` ~ `슬라이스27.png`
- 4번: `슬라이스28.png` ~ `슬라이스33.png`
- 5번: `슬라이스34.png` ~ `슬라이스42.png`
- 6번: `슬라이스43.png` ~ `슬라이스51.png`
- 7번: `슬라이스52.png` ~ `슬라이스60.png`
- 8번: `슬라이스61.png` ~ `슬라이스70.png`
- 9번: `슬라이스71.png` ~ `슬라이스77.png`

각 번호를 누르면 해당 범위의 사진이 한 장씩 나오고,
오른쪽 아래 `넘기기 ▶` 버튼으로 다음 사진으로 넘어갑니다.

`⌂ 첫 화면` 버튼을 누르면 9명 선택 화면으로 돌아갑니다.
